# 中文版怎么写

产品的 writing_guide 有更具体的要求时，以它为准。

## 选词：先查当地人怎么搜

英文主词直译成中文常常搜不到同一类内容。英文 `ai cover generator` 搜的是 AI 翻唱，中文「AI 封面生成」搜的才是
做封面图。每个中文页面的主词（title、H1、summary 里的主语）都要单独确认：

1. 把主词回译成英文，问自己「中文用户搜这个词想要什么」。
2. 查百度联想：`https://suggestion.baidu.com/su?action=opensearch&wd=<URL 编码的词>`，返回 GBK 编码的 JSON，
   第二项是联想词列表。联想全是别的意思、或者为空，就换词。
3. 两种说法都有人搜（比如「评测」和「测评」），就都用上：一个进标题，另一个进描述或正文，不要只留一个。

## 排版

- 汉字和拉丁字母、数字之间加一个空格：「用 Python 3 写的脚本，支持 PNG 和 JPEG」。
- 用全角标点（，。：；？！「」），英文专名内部保持原样。
- 不用斜体，不用引用块（`>`）。
- FAQ 的问题以「？」结尾。

## 长度

标题 30–62 显示列、描述 110–160 显示列，汉字算 2 列。中文标题大约 15–31 个字，描述大约 55–80 个字。

## 和默认语言版本保持一致

事实、数字、日期、来源、关联、图片和英文版完全一致，不多也不少。翻译时发现英文版有错，先改英文版，
再同步中文版，不要只改一边。

## lint 的已知缺口

hub 的「FAQ 首句至少 5 个词」按空格数词，中文答案的首句常被判太短，扣 3 分。不要为了凑分在中文里加空格或英文词，
如实写；分数够门槛就行。
